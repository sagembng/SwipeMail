Principles

Glass on chrome onlyTabs, buttons and the app frame are frosted. Email cards use a high-opacity glass so text never fights the background.
One colour per meaningViolet acts, cyan means read, orange means starred, rose means urgent. Nothing else is coloured.
Depth from the stackCards peek above the top one, so the pile reads as "what is left".
Keyboard firstIt is a web app: arrow keys swipe, Z undoes, hold Space to read the whole email.

Colour

I tried Google's blue, green, yellow and red first. They fought the logo's cyan, violet and coral, so the roles now use the logo's hues. Dark mode lifts each one to a lighter tint, the same inversion Google uses.
